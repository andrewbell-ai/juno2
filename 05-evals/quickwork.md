Chosen piece: Juno’s possible duplicate idea suggestions.
1. While using it: I’d notice a bad suggestion when the two ideas sound similar but their source evidence shows customers want different things.
2. Human review: A PM reviews a random sample of 10 suggestions each week—or all of them if there are fewer—and labels each as a true or false match.
3. Automated check: A script fails any suggestion that lacks links to the source records for both ideas, or that merges ideas without PM approval.
⭕ Hardest: Human review. It takes time to label examples consistently, especially when two requests partly overlap.
